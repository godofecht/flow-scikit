methodology and reproducibility

Every claim should be traceable to code.

Timing units

bench_sklearn.py captures seconds from perf_counter(); the report converts them to milliseconds. bench_flow.flow converts clock() ticks to milliseconds internally.

Dataset split

The headline Python and Flow benchmarks use the same deterministic xorshift32 Fisher–Yates split with seed 42 and an 80/20 train/test partition.

What speedup means

Speedup is always Python milliseconds / Flow milliseconds. Values above 1× mean Flow is faster; values below 1× mean Python is faster.

Separate parity suite

The 16-algorithm parity test uses fixed deterministic datasets and parameters. It is not conflated with the iris/digits/diabetes predictive-score benchmark.
