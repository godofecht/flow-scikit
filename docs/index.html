library design

Familiar estimators with explicit data and decision steps.

01

Native execution

Flow emits native code, so model logic can ship without embedding a Python runtime or package environment.

02

Observable behaviour

Scores, predictions, thresholds, and benchmark parameters are kept explicit so comparisons remain inspectable.

03

Parity as a test target

Deterministic reference cases compare Flow outputs directly against sklearn rather than treating API similarity as correctness.

Fit, predict, inspect.

The aggregate module exposes the library from one import; individual modules remain available for implementation-level inspection.

import "lib/scikit/scikit.flow"

let model = knn_classifier_fit(X_train, y_train, 5)
let predictions = knn_classifier_predict(model, X_test)
let score = accuracy_score(y_test, predictions, n_test)
